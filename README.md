# Chic Cart

Build a modern, responsive e-commerce website with the following structure:

Header (sticky/fixed navigation bar):

Logo/brand name on the left
Navigation links: About, Contact, Services
A "Login" button on the right (styled as a distinct CTA button)
Mobile-responsive hamburger menu for smaller screens

Body (main content):

A hero/banner section at the top with a catchy headline and CTA button
A product showcase section using card components, displaying products in categories like Watches, Phones, and other electronics
Each card should include: product image, product name, price, and an "Add to Cart" or "View Details" button
Cards should be arranged in a responsive grid (e.g., 3-4 per row on desktop, 1-2 on mobile)
Add hover effects on cards (slight scale-up or shadow on hover)
Include a "Shop by Category" section with categories: Watches, Phones, Accessories

Footer:

Social media icons (Instagram, Facebook, Twitter/X, LinkedIn) with links
"Terms & Conditions" and "Privacy Policy" links
Contact email: kunal832006@gmail.com
Location/address section
Copyright text at the bottom

Design preferences:

Clean, modern e-commerce aesthetic (similar to Amazon/Flipkart style but minimal)
Use a consistent color scheme (e.g., a primary brand color + white/neutral background)
Smooth transitions and hover animations
Fully responsive across mobile, tablet, and desktop
Use placeholder product images for watches and phones for now
